# tradermarketcap-open

Add an ENA supply rule with locked wallets excluded

## Overview

**Bounty: 1 RESET** (paid when merged, see CONTRIBUTING.md)

**Done when:** a new `tokens` rule for ENA (Ethereum contract 0x57e114B691Db790C35207b2e685D4A43181e6061) is added to data-seed/coins.json, with every non-circulating wallet (core contributors, foundation, ecosystem) proven by a primary source: Ethena's own documents/announcements or an explorer label. Untagged top holders are not enough. If the wallets can't be proven, circulating must not be published (no overstating).
